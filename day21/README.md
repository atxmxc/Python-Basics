## Weather CLI Tool (MILESTONE FOR DAY20)  
- This tool allows you to find the temperature of any city and export them to csv or json as well as get a report of all samples collected, min temp, max temp and avg temp

## USAGE  
- python day20/project.py --city London --save  
- python day20/project.py --report --city London --since 24h
- python day20/project.py --export  
- python day20/project.py --report
